# Account Abstraction

[

## 📄️ Overview

BOT Chain provides two complementary account abstraction capabilities: ERC-4337 uses smart accounts and a Bundler to provide the UserOperation path, while EIP-7702 allows an existing EOA to delegate its account implementation while retaining its original address. ERC-4337 is currently the primary path for production integrations.

](https://dev-docs.botchain.ai/docs/Account-Abstraction/overview)

## 📄️ EIP-7702

BOT Chain Mainnet and Testnet support EIP-7702 type 4 transactions. An existing EOA can sign an authorization that delegates its execution code to a deployed account implementation while retaining the original EOA address, balance, and private-key control.

](https://dev-docs.botchain.ai/docs/Account-Abstraction/eip-7702)
